# 📝 React Blog Management App (Redux Toolkit)

A modern and responsive **Blog Management Application** built with **React.js** and **Redux Toolkit**. This project demonstrates complete **CRUD (Create, Read, Update, Delete)** operations while implementing centralized state management using Redux Toolkit. It also includes **Search**, **Category Filter**, and **Local Storage** for persistent data.

---

## 🚀 Features

- ➕ Add New Blog
- 📖 View All Blogs
- ✏️ Edit Existing Blog
- 🗑️ Delete Blog
- 🔍 Search Blogs by Title or Description
- 🏷️ Filter Blogs by Category
- 💾 Store Blogs in Local Storage
- ⚡ Global State Management using Redux Toolkit
- 📱 Fully Responsive User Interface

## ✨ Functionalities

### ➕ Add Blog

Users can create a new blog by entering:

- Blog Title
- Blog Description
- Blog Category
- Date (Generated Automatically)

---

### 📖 View Blogs

Display all blogs in a clean and responsive card layout.

---

### ✏️ Edit Blog

Update any existing blog instantly.

---

### 🗑️ Delete Blog

Delete blogs with a single click.

---

### 🔍 Search Blogs

Search blogs by:

- Title
- Description

---

### 🏷️ Filter Blogs

Filter blogs based on categories:

- Technology
- Education
- Sports
- Health
- Business

---

### 💾 Local Storage

Blog data is stored in the browser's Local Storage so that all blogs remain available even after refreshing the page.

## ⚙️ Installation

### Clone the Repository

```bash
git clone https://github.com/RoushanGoswami/react-blog-management.git
```

### Navigate to the Project

```bash
cd react-blog-management
```

### Install Dependencies

```bash
npm install
```

### Start Development Server

```bash
npm run dev
```
